# Develop the bundled Product Changelog theme

This format-v2 package is generated from the independent sources under `src/`. Run `yarn workspace @microfeed/changelog-theme-source build`, `validate`, and `test` after editing. Increment the immutable manifest version before changing released bytes.

The portable package has eight generated text slots, a theme-specific preview fixture, and no packaged binary assets. Timeline entries remain normal focusable links and use text labels in addition to color-coded release types.
