<section class="home-section">
  <h2>Why microfeed</h2>
  <div class="why-grid">
    <article class="why-card">
      <h3>Open source</h3>
      <p>Own <span class="brand-highlight">your code</span> and <span class="brand-highlight">your data</span>. Deploy microfeed into your own <span class="cloudflare-brand">Cloudflare</span> account.</p>
    </article>
    <article class="why-card">
      <h3>Serverless</h3>
      <p><span class="cloudflare-brand">Cloudflare</span> Workers, D1, and optional R2 run the site without a server for you to patch or maintain.</p>
    </article>
    <article class="why-card">
      <h3>Free-tier friendly</h3>
      <p>Many personal and small sites can stay within <span class="cloudflare-brand">Cloudflare’s</span> included usage. Check the current <a href="https://developers.cloudflare.com/workers/platform/pricing/">Workers</a>, <a href="https://developers.cloudflare.com/d1/platform/pricing/">D1</a>, and <a href="https://developers.cloudflare.com/r2/pricing/">R2</a> allowances as your audience grows.</p>
    </article>
    <article class="why-card">
      <h3>Headless</h3>
      <p>Publish in the visual dashboard or connect another app or coding agent through the authenticated API and official <a href="https://www.npmjs.com/package/@microfeed/cli"><code>@microfeed/cli</code></a>.</p>
    </article>
  </div>
</section>

  <h2>Features</h2>
  <ul class="feature-list">
