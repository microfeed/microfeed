<section class="home-section">
  <h2>Why microfeed</h2>
  <div class="why-grid">
    <article class="why-card">
      <h3>Open source</h3>
      <p>Own <span class="brand-highlight">your code</span> and <span class="brand-highlight">your data</span>. Deploy microfeed into your own <span class="cloudflare-brand">Cloudflare</span> account.</p>
    </article>
    <article class="why-card">
      <h3>Serverless</h3>
      <p><span class="cloudflare-brand">Cloudflare</span> Workers, D1, and optional R2 replace a traditional server stack.</p>
    </article>
    <article class="why-card">
      <h3>Free-tier friendly</h3>
      <p>Many small sites can stay within <span class="cloudflare-brand">Cloudflare’s</span> included usage. <a href="https://developers.cloudflare.com/r2/pricing/">Standard R2 includes 10 GB-month of storage and free egress</a>.</p>
    </article>
    <article class="why-card">
      <h3>Headless</h3>
      <p>Publish and automate through an authenticated Admin API with OpenAPI and agent-ready references.</p>
    </article>
  </div>
</section>

<section class="home-section">
  <h2>Quick start</h2>
  <div class="quick-start-list">

1. Clone the microfeed repository.

   ```console
   git clone https://github.com/microfeed/microfeed.git
   ```

2. Open the new `microfeed` folder in a local coding agent.

3. Ask the agent:

   ```text frame="terminal"
   Deploy microfeed to Cloudflare.
   ```

  </div>
  <p><a href="/start-here/ai-agent/">Follow the complete AI-agent deployment guide</a> for browser handoffs, verification, and recovery guidance.</p>
</section>
